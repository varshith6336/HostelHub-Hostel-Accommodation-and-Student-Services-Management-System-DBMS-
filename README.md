# HostelHub --- Hostel Accommodation & Student Services Management System **DBMS Project 06**\ **Student:** Navari Varshith Reddy\ **Roll No.:** 25WU0102181\ **Mentor:** Dr. Cheekati Nagaraju\ **University:** Woxsen University ## Project Overview HostelHub is a hostel accommodation and student-services management interface designed to organize student records, rooms and beds, bed allocations, complaints, visitor entries, and reports. ## Project Presentation [**Open or download the HostelHub DBMS Presentation (.pptx)**](./HostelHub_DBMS_Presentation.pptx) > Keep `HostelHub_DBMS_Presentation.pptx` in the same root folder as > this `README.md`. The link must match the uploaded filename exactly. ## Main Features -   Dashboard with hostel summary information -   Student directory -   Room and bed inventory -   Bed allocation interface -   Complaints and maintenance tracking -   Visitor log -   Reports and summary figures ## Technologies -   HTML -   CSS -   JavaScript -   Python Flask starter API -   MySQL database schema ## Repository Files -   `index.html` --- HostelHub website interface -   `app.py` --- Starter Flask API -   `requirements.txt` --- Python dependencies -   `database/hostelhub.sql` --- MySQL schema (upload this file if it is not already in the repository) -   `HostelHub_DBMS_Presentation.pptx` --- Project presentation ## Important Note The website is currently a demonstration frontend using sample data in browser memory. The frontend is not yet connected to the MySQL database, and the Flask API requires configuration and deployment before it can be used online. ## How to View the Website Open `index.html` in a web browser, or configure GitHub Pages in the repository settings to publish the static frontend.
